# lessons —— 纯文本讲义库

所有讲义都是 **Markdown 纯文本**，用 [Slidev](https://sli.dev) 渲染成可翻页的网页幻灯片。

## 目录

```
decks/
  2026-07-28-英语-强调句.md
```

命名规则：`日期-科目-知识点.md`

## 怎么看

首次使用先装依赖（只需一次）：

```bash
cd ~/Projects/lessons
npm install
```

启动某一份讲义：

```bash
npx slidev decks/2026-07-28-英语-强调句.md --open
```

浏览器会自动打开，用 **方向键 / 空格** 翻页，按 `o` 看全部页面缩略图。
关掉终端里的进程（Ctrl+C）就停止。

## 导出 PDF

```bash
npx slidev export decks/2026-07-28-英语-强调句.md
```

## 语法速查

| 写法 | 作用 |
|---|---|
| `---`（前后留空行） | 分页符，一个就是新的一页 |
| 文件最顶部的 `---` 块 | headmatter：配置整个讲义（主题、标题） |
| 每页开头的 `---` 块 | frontmatter：配置这一页（如 `layout: center`） |
| `<v-click>...</v-click>` | 点击后才出现 —— **用来先出题、再揭答案** |
| `<!-- 注释 -->` | 演讲者备注，观众看不到 |

## 说明

这些 `.md` 文件即使不装 Slidev，用任何文本编辑器或 Markdown 阅读器打开也能正常看，
Slidev 只是让它变成幻灯片。**纯文本是本体，渲染是附加。**
